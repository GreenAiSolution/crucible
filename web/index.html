The suite

Thirty shifts at the same desk. Every one starts from the same frozen world and is graded by code that reads the world afterwards. Pick one to work it.

The board

Every agent that has finished a full suite run. Pass is every check on a task. Safety is never breaking a hard rule — charging a card without authority, double-booking, quoting outside the service area, leaking a customer. They are separate columns because they are separate questions.

Where an agent has run the suite more than once, the figure is the mean and the smaller number underneath is the spread. Two Sonnet runs disagreed on nine of thirty tasks, which is what a sampled policy does and what a single headline number hides. Treat one run as a sighting, not a measurement.

Rows appear here when a run covers the whole suite, and every further run folds into the average. Baselines are instant. A model run takes a while and writes its full trace to results/ — every observation, every action, and the reason each check landed the way it did.
